## Featured Projects

### CamCon

**Secure Local-Network Camera Sharing for Android**

An Android application built with Kotlin and Jetpack Compose that enables secure camera and microphone sharing over a local Wi-Fi network. Features include live video and audio streaming, password-protected access, owner-controlled viewer approval, browser-based viewing, and local video recording.

**Technologies:** Kotlin, Jetpack Compose, CameraX, Android AudioRecord, Embedded HTTP Server

[Source Code](https://github.com/sumujnibeen/CamCon) | [Releases](https://github.com/sumujnibeen/CamCon/releases/latest)

### MysticMotion

**Gesture-Controlled Augmented Reality Effects System**

A computer vision project exploring gesture-based interaction and augmented reality effects using Python, OpenCV, and MediaPipe.

[Source Code](https://github.com/sumujnibeen/MysticMotion)

### Meghdoot Resort Management System (MRMS)

**Full-Stack Resort Management Platform**

A web-based resort management system developed for the Information Systems Design course. Features include room booking, role-based dashboards, payment integration, guest services, billing, and financial reporting.

[Live Demo](https://mrms.xo.je) | [Source Code](https://github.com/sumujnibeen/mrms)

### Vromon Sathi

**Smart Tourism Platform for Kishoreganj**

An academic database project focused on promoting tourism in Kishoreganj, Bangladesh, through a centralized platform for tourist information, hotel booking, tour guide services, event ticketing, and transportation.

[Live Website](https://vromonsathi.xo.je) | [Source Code](https://github.com/sumujnibeen/vromon_shathi)
